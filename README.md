# Virtual Pro Wrestling 64: Recompiled (bootstrap)

Native PC port of Virtual Pro Wrestling 64 (N64, Japan) via
[N64Recomp](https://github.com/N64Recomp/N64Recomp) static recompilation, running
on N64ModernRuntime (ultramodern + librecomp) with RT64 as the renderer. Fourth
project in the AKI-engine recomp family, following WCW vs. nWo World Tour:
Recompiled (its direct 1997 sibling), WCW/nWo Revenge: Recompiled, and WWF
WrestleMania 2000: Recompiled — see those projects for the shared architecture
and build documentation.

Not an emulator, not a decompilation. No game assets are distributed; you supply
your own ROM (Japan release).

Status: pre-bootstrap — repo skeleton is in place; ROM recon has not started.
